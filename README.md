# Impervia: Privacy-Aware Academic Assistant

Impervia protects students' privacy before their academic queries reach AI models.

## Project Architecture

- **Backend**: Python + FastAPI + SQLAlchemy 2.0 + Aiven PostgreSQL (see [backend/README.md](file:///d:/EDI/EDI'3_sem/backend/README.md))
- **Privacy Handler**: In-memory inspection, PII detection, sensitive content filtering, academic relevance detection, and privacy decision engine.
- **Frontend**: Academic chatbot interface (planned).
